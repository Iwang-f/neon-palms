NEON PALMS is an original open-world crime game that runs in the browser straight from static files. It is set in the island city of Palma Sol, and it ships with six story missions, a five-star police response, traffic and pedestrians, a HUD with a radar, and a synthesised radio.

## Run it

```
node serve.ts
```

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Controls: WASD to move, MOUSE to look, CLICK to shoot, E to interact, SHIFT to sprint, R to reload, TAB for the map, ESC to pause.
