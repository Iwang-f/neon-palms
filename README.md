NEON PALMS is an original open-world crime game that runs in the browser straight from static files. You play in Palma Sol, an island city of sun-bleached streets and neon nightlife, and work your way through six story missions while a five-star police response escalates behind you. Traffic and pedestrians fill the roads, a HUD with a radar keeps you oriented, and the whole soundtrack is a synthesised radio that builds as the heat rises.

## Run it

```
node serve.ts
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Controls: WASD to move, MOUSE to look, CLICK to shoot, E to enter and exit vehicles, SHIFT to sprint, R to reload, TAB for the map, ESC to pause.
