NEON PALMS is an original open-world crime game that runs in the browser, set in the sun-bleached city of Palma Sol. Six story missions carry you through its streets, with a five-star police response that escalates as you make noise. Traffic and pedestrians fill the roads, a HUD with a radar keeps you oriented, and a synthesised radio soundtrack plays as you drive.

## Run it

```
node serve.ts
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

**WASD** move / drive · **MOUSE** look / aim · **CLICK** fire · **E** enter / exit vehicle · **SHIFT** sprint / handbrake · **R** radio · **TAB** map · **ESC** pause
