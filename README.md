NEON PALMS is an original open-world crime game that runs in the browser straight from static files. It is set in the island city of Palma Sol, where six story missions unfold across a living world: a five-star police response hunts you through the streets, traffic and pedestrians fill the roads and sidewalks, a HUD with a radar keeps you oriented, and a synthesised radio soundtrack carries the mood.

## Run it

```
node serve.ts
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Controls: WASD to move, MOUSE to look, CLICK to fire, E to interact, SHIFT to sprint, R to reload, TAB to check the map, ESC to pause.
