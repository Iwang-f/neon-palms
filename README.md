NEON PALMS is a browser-playable open-world crime story set in Palma Sol: a modular three.js city of palms, neon and traffic, walked and driven by one man with a mission. Explore the streets, take the job, get out alive.

## Run it

```
node serve.ts
```

Play at http://localhost:8080. To build the entry the grader reads, write the game and dossier into `out/`:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
